# Night Vision Practice / 夜間視野模擬練習

Browser-based practice tool for becoming familiar with a low-contrast Landolt-C style night-vision test with optional glare interference.

## Updated in this revision
- C brightness slider now supports **0** for extremely dark targets
- Difficulty presets renamed to plain-language labels
- Larger yellow glare lamps
- Brighter visible filament inside the lamp
- Stronger dark-target practice, closer to “hard to even locate the C” conditions

## Notes
This is still a practice/simulation tool only. It does **not** reproduce the real optical calibration, luminance, or lux conditions of a clinical testing device.
