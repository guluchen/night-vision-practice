# Night Vision Practice / 夜間視野模擬練習

A small browser-based practice tool for becoming familiar with a low-contrast Landolt-C style night-vision test with glare.

## Features
- 8-direction Landolt C targets
- Adjustable target contrast and size
- Normal, glare, and glare-recovery modes
- Keyboard and mobile touch controls
- Accuracy and reaction-time statistics
- No build step; suitable for GitHub Pages

## GitHub Pages
Publish the repository root from the `main` branch using GitHub Pages.

> This is a practice/simulation tool only. It does not reproduce the optical characteristics of an official testing device and cannot predict medical or licensing-test results.
