這版怎麼看難易度

  • C 亮度 / 對比數值越低 → C 越暗 → 越難。
  • 0 代表幾乎貼近黑背景，可能會難到連 C 在哪裡都不好找。
  • 5 是這版預設，故意比前一版暗很多。
  • 如果覺得還不夠像實際體檢，就把亮度往 0–3 調，並搭配兩道中／高眩光。

目前版本新增

  • 可切換 0 / 1 / 2 道黃光眩光。
  • 黃光燈泡加大，燈絲改成更亮，並故意保留容易誤導視線的感覺。
  • 用「極難 / 很難 / 中等 / 較容易 / 容易」取代不直觀的舊對比標示。
  • 保留自訂滑桿，可微調到更接近實際體檢的手感。

使用方式

  1. 先在一般模式熟悉 C 字缺口的 8 個方向。
  2. 再切到「眩光干擾」或「眩光恢復」，練習忽略左側黃光、快速辨認右側目標。
  3. 如果覺得黃光太像目標本體，可刻意只把注意力固定在右側區域，不要直接去看燈絲。
  4. 電腦可用數字鍵盤 1–9（不含 5）或方向鍵；手機直接按方向按鈕。
  5. 正式補檢時，若使用漸進多焦鏡片，先確認測試距離與自己應該使用的鏡片區域。

註：眩光強度的低／中／高是螢幕上的相對模擬，並非真實 lux 校準。
